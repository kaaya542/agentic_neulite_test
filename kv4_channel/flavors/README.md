The following are extensions of the vanilla kernel:

* mpi: A generic MPI version.
* kv1_1: A single-process perisomatic extension with the BMTK Kv11.mod ionic current. See [example](../examples/kv1_1/README.md).
* kv4_3: A single-process perisomatic extension with the BMTK Kv43.mod A-type potassium current, derived from vanilla. See [example](../examples/kv4_3/README.md).
