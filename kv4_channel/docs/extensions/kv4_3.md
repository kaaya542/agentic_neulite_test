# Kv4_3の仕様

Allenモデル472363762の体細胞へKv4_3（A型K⁺電流）を追加する。[実行・検証](../testing.md#kv4_3例) · [結果](../results/kv4_3.md)

## 目的・参照

- 基盤：Neulite 1.2.0のvanilla `kernel/`（`38c2f926e2862e61e784fd3569bf3fc30e2bf1bb`）。Kv1_1 flavorとは独立。
- [Kv43.mod](../../test/kv4_3/reference/Kv43.mod)、`SUFFIX Kv4_3`。BMTK `2403909fe597021c2c275311d60c79461bbc75d9`の`docs/tutorial/01_opt_external_models/components/mechanisms/modfiles/`から取得。[出典・ハッシュ](../../test/kv4_3/reference/sources.json) · [ライセンス](../../test/kv4_3/reference/BMTK-LICENSE.txt)
- MOD内の記載：小脳顆粒細胞のKA電流（E. D'Angelo, T. Nieus, A. Fontana、2003年改訂）、GRC_KAからKv4_3へ改名。BMTKでは`Purkinje_morpho_1.py`が`gkbar_Kv4_3`として使う。検証対象は配布MOD。
- 元パラメータと形態はKv1_1例と同じ（[472363762_fit.json](../../examples/kv1_1/reference/472363762_fit.json)、`test/kernel-test/data/Scnn1a_473845048_m_c.swc`）。

Kv4_3は元のAllenモデルに含まれない機構。

## 条件

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 配置・実行 | 体細胞、単一プロセス | 依頼者と合意 |
| 状態 | 活性化`a`、不活性化`b`、無次元 | MOD |
| 温度 | 34 ℃ | 元モデルの`conditions.celsius`。MODの`celsius = 30`はNEURONでは全体の`celsius`で上書きされる |
| 反転電位 | E_K=−107 mV、既存の`V_K`を共有 | 元モデル |
| 密度 | 0と0.0032 S/cm²（`gkbar_Kv4_3`）。非負有限値を指定可能 | MOD既定値、依頼者と合意。実細胞への適合性は未評価 |
| 初期化 | 初期電位 −92.49911499023438 mV における`a_inf`・`b_inf` | MODの`INITIAL` |
| 刺激 | 0.12 nA、500–1500 ms、全長2000 ms、dt=0.1 ms | Kv1_1例と同じ比較条件 |

## 数式・単位

VはmV、時間はms、速度定数は1/ms。`sigm(x, y) = 1 / (exp(x / y) + 1)`。

```text
Q10      = 3 ** ((34 - 25.5) / 10)
alpha_a  = Q10 * 0.8147 * sigm(V + 9.17203, -23.32708)
beta_a   = Q10 * 0.1655 / exp((V + 18.27914) / 19.47175)
alpha_b  = Q10 * 0.0368 * sigm(V + 111.33209, 12.8433)
beta_b   = Q10 * 0.0345 * sigm(V + 49.9537, -8.90123)
a_inf    = 1 / (1 + exp((V + 38) / -17))
b_inf    = 1 / (1 + exp((V + 78.8) / 8.4))
tau_x    = 1 / (alpha_x + beta_x)
x(t+dt)  = (x(t) + dt * x_inf / tau_x) / (1 + dt / tau_x)   [x = a, b; V は更新後]
j_K      = gkbar * a**3 * b * (V - E_K)  [mA/cm²]
```

- 定常値`a_inf`・`b_inf`はalpha/betaから求めず、MODと同じく独立のシグモイドを使う。Q10は時定数だけにかかる。
- MODは`METHOD derivimplicit`。この線形ゲートではNEURONのNewton法が後退Euler法に一致するため、カーネルも後退Euler法で更新する（既存チャネルの指数Euler法とは異なる）。
- MODの`TABLE`（−100～30 mV、13000点、範囲外は端の値）は使わず、式を直接評価する。
- 入力時に`gkbar_total = gkbar * area_cm² * 1e3`でS/cm²からmSへ換算する。`g = gkbar_total * a**3 * b`、`I_K = g * (V-E_K)`はµA。行列には`lhs += g`、`rhs += g * E_K`を加える。

変更箇所は`flavors/kv4_3/`の`ion.h`（`G_KV43`、`A_KV43`・`B_KV43`）、`ion_func.h`（式）、`ion.c`（初期化・更新・電流）、`popl_func.h`（24列）。

## 入力

- `NeuliteBuilder(..., kernel_flavor="kv4_3")`を指定する。
- Allen形式の`genome`へ`section="soma", mechanism="Kv4_3", name="gkbar_Kv4_3", value=<S/cm²>`を追加する。パラメータ名はMODの`gkbar`に合わせる。
- vanillaは23列、Kv4_3は末尾に密度を加えた24列。未指定のKv4_3密度は0。
- 非数値・非有限値・負の密度、重複、`gbar_Kv4_3`などの別名、未対応の機構・配置を拒否する。温度34℃、体細胞ek=−107 mV・ena=53 mVを確認する。
- vanilla・kv1_1へのKv4_3指定、kv4_3へのKv1_1指定はエラー。

## 検証基準

基準は実装前に定め、Kv1_1と同じ許容差を使う。

| 検証 | 条件・基準 |
| --- | --- |
| 定常値・時定数 | −120～60 mV、1 mV刻み。独立式・元MOD（`usetable=0`、MOD本文のパラメータ）と比較、相対・絶対許容差1e−12 |
| 初期化・電圧ステップ | −90→−40、−40→−100、−107→−107、−100→20 mV。dt=0.1/0.05/0.025 ms、50 ms（`tau_b`が−40 mVで約15 msのため）。後退Euler法の閉形式・元MODと比較、相対・絶対許容差1e−10。反転電位で電流0 |
| 電流・面積換算 | 2面積で実際の`calc_lhs_and_rhs`と独立式を比較 |
| 入力生成 | BMTK→bionetlite→CSV→Cで密度と総コンダクタンスを照合。23列CSVの拒否 |
| 無効時回帰 | 同じJSONから生成したvanillaとgkbar=0でv.dat/s.datがバイト一致 |
| 有効時 | gkbar=0.0032で有限値、膜電位が変化 |
| 故障注入 | a³→a²、温度補正なし、後退Euler→指数Euler、換算係数の誤りを検出 |

元MODの電圧固定検証は、状態更新中のgkbarを0にし、各評価点で戻して`fcurrent`を計算する。

### 参考値（合否判定に使わない）

- NEURON 9.0.1のnocmodlはPARAMETER既定値を6桁で保存する（例：`Kalpha_a` −23.32708→−23.3271）。照合ではMOD本文の値をNEURONへ明示的に設定する。既定値・TABLEありのNEURONとの差は、TABLE範囲内の速度式で相対8.7e−6、範囲外（−107 mVなど）では端の値に固定されるため大きく異なる。
- 後退Euler法と連続解の差は、dtを半分にすると約半分になる（−90→−40 mV）。−100 mVでは`tau_a`≈0.04 msとdtより短いため、収束域に入らない。

## 電流記録

`examples/kv4_3/current_recording.py`が検証済みカーネルのコピーへ観測コードを加え、`solve`直前の電圧・ゲート・Ca濃度で瞬時電流を記録する。列はKv1_1の[電流記録](kv1_1-recording.md)と同じで、ゲート列は`a_Kv4_3`・`b_Kv4_3`。全チャネルの観測は共通の`test/kv1_1/current_probe.c`で行列寄与と照合する。

全細胞のBioNet一致、全区画配置、MPI、別温度、MODのTABLE近似の再現は検証対象外。
