# Kv4_3追加前後の膜電位と電流

[仕様](../extensions/kv4_3.md)の条件で、Allen 472363762の体細胞にKv4_3を0と0.0032 S/cm²で加えて比較した。34℃、E_K=−107 mV、0.12 nA・500–1500 ms、dt=0.1 ms、単一プロセス。NEURON 9.0.1、BMTK `2403909`。

## 再現

```sh
python -m pip install -r examples/kv4_3/requirements.txt
python test/kv4_3/verify.py --output _runs/kv4_3-check-01
python examples/kv4_3/record_currents.py --verification-dir _runs/kv4_3-check-01 --output _runs/kv4_3-currents-01
python examples/kv4_3/plot_currents.py --recording-dir _runs/kv4_3-currents-01 --output _runs/kv4_3-figures-01
```

`_runs/kv4_3-figures-01/index.html`に図4枚、PDF、時系列CSV入りZIP、電流集計CSVを出力する。

## 検証

| 項目 | 結果 |
| --- | --- |
| 速度式：C対独立式・元MOD | 最大絶対誤差2.8e−14（基準1e−12） |
| 電圧ステップ：C対後退Euler閉形式・元MOD | 5.3e−14・8.7e−14（基準1e−10） |
| 入力生成 | 不正入力14件を拒否、正常4件。CSV→Cの総コンダクタンス誤差0 |
| 無効時回帰 | gkbar=0とvanillaのv.dat/s.datがバイト一致 |
| 故障注入 | 冪・温度補正・積分法・単位換算の4種を検出 |
| 電流記録 | 記録あり・なし・元のv.dat/s.datがバイト一致。ゲート再計算誤差1e−12未満 |
| 回帰 | `test/kv1_1/verify.py`、`tools/run_baseline.py`が合格 |

## 結果

| 指標 | 追加前（0） | 追加後（0.0032 S/cm²） |
| --- | --- | --- |
| 発火数 | 17 | 17 |
| 刺激開始から初発火 | 54.6 ms | 56.2 ms |
| 最大膜電位 | 41.36 mV | 38.88 mV |
| 刺激中のKv4_3電流 最大・平均 | 0 | 0.208 nA・0.00197 nA |

- 各スパイクは0.3～5.4 ms遅れ、5発目以降は遅れが累積して最後の2発で5.4 ms。膜電位の最大差98 mVは時刻ずれによるもの。
- Kv4_3電流は初発火で最大0.208 nA、以後は不活性化ゲート`b`の低下により約0.043 nAまで減る。スパイク間はほぼ0。
- 既存K⁺電流のピークはやや低下した（例：Kv3_1 1.77→1.76 nA、Im 0.578→0.525 nA）。

電流はnA、イオン電流は外向きが正。容量性・軸方向・シナプス電流は含まない。電流比は発火への寄与率ではない。既存チャネルの変化には膜電位・ゲート状態の変化も含まれる。

## 検証範囲

単一細胞の体細胞のみ。生理学的な密度の妥当性、全細胞のBioNet一致、全区画配置、MPI、別温度、MODのTABLE近似は評価していない。
