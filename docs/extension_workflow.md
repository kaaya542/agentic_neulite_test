# 拡張手順

1. 対象資料・モデルの版、入力、期待する出力、比較条件を決める。
2. [アーキテクチャ](architecture.md)をもとに、入力生成から実行までの経路を調べる。
3. [仕様](extension_spec_template.md)に参照データ・式と許容差を定め、必要な箇所を実装する。
4. 機能単位、入力から実行までの経路、既存機能への回帰を検証する。
5. 比較結果、図・元データ、再現コマンド、検証範囲を示す。

| 対象 | 主な確認点 |
| --- | --- |
| tutorial・実行例 | 刺激、入力生成、実行設定、参照出力 |
| 入力・接続 | ノード・区画ID、重み、時刻・遅延・単位、イベントの伝達 |
| シナプス・チャネル | 数式、状態、初期化、更新順序、電流 |
| 並列化 | 状態の所有、分割・通信、乱数、直列との比較 |

入力例は`examples/<name>/`、検証は`test/<name>/`へ置く。カーネル変更が必要なら`flavors/<name>/`を作る。仕様と結果は`docs/extensions/`、`docs/results/`へまとめる。
