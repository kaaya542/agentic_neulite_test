# Kv1_1の仕様

Allenモデル472363762の体細胞へKv1_1イオン電流を追加する。[検証の実行方法](../testing.md)

## 参照

- 基盤：Neulite 1.2.0、`38c2f926e2862e61e784fd3569bf3fc30e2bf1bb`。
- [Kv11.mod](../../test/kv1_1/reference/Kv11.mod)、`SUFFIX Kv1_1`。BMTK `2403909fe597021c2c275311d60c79461bbc75d9`の`docs/tutorial/01_opt_external_models/components/mechanisms/modfiles/`から取得。[出典・ハッシュ](../../test/kv1_1/reference/sources.json) · [ライセンス](../../test/kv1_1/reference/BMTK-LICENSE.txt)
- [元パラメータ](../../examples/kv1_1/reference/472363762_fit.json)も同じBMTK版。形態は`test/kernel-test/data/Scnn1a_473845048_m_c.swc`。
- MOD内の文献：Akemann et al., Biophysical Journal 96:3959–3976 (2009)、Zerr et al. (1998)。検証対象は配布MOD。

Kv1_1はBMTKの外部モデル由来。元のAllenモデルに含まれる機構ではない。

## 条件

| 項目 | 値 |
| --- | --- |
| 配置・実行 | 体細胞、単一プロセス |
| 状態 | 活性化ゲート `n`、無次元 |
| 温度 | 34 ℃ |
| 反転電位 | E_K=−107 mV、既存の`V_K`を共有 |
| 密度 | 0と0.004 S/cm²。非負有限値を指定可能 |
| 初期化 | 元モデルの初期電位 −92.49911499023438 mV における定常値 |
| 電流 | `gateCurrent=0`のイオン電流 |
| 刺激 | 0.12 nA、500–1500 ms、全長2000 ms、dt=0.1 ms |

密度0.004 S/cm²はMOD既定値。実細胞への適合性は未評価。

## 数式・単位

VはmV、時間はms、速度定数は1/ms。

```text
alpha(V) = 0.12889 * exp((V + 45) / 33.90877)
beta(V)  = 0.12889 * exp(-(V + 45) / 12.42101)
qt       = 2.7 ** ((34 - 22) / 10)
n_inf    = alpha / (alpha + beta)
tau_n    = 1 / (qt * (alpha + beta))
dn/dt    = (n_inf - n) / tau_n
n(t+dt)  = n_inf + (n(t) - n_inf) * exp(-dt / tau_n)
j_K      = gbar_density * n**4 * (V - E_K)  [mA/cm²]
```

入力時に`gbar_total = gbar_density * area_cm² * 1e3`でS/cm²からmSへ換算する。
`g = gbar_total * n**4`、`I_K = g * (V-E_K)`はµA。行列には`lhs += g`、`rhs += g * E_K`を加える。

`initialize_ion`、`update_ion`、`calc_lhs_and_rhs`へ接続する。積分法・既存機構の更新順序はvanillaと共通。

## 入力

- `NeuliteBuilder(..., kernel_flavor="kv1_1")`を指定する。
- Allen形式の`genome`へ`section="soma", mechanism="Kv1_1", name="gbar_Kv1_1", value=<S/cm²>`を追加する。
- vanillaは23列、Kv1_1は末尾に密度を加えた24列。未指定のKv1_1密度は0。`N_GBAR=16`。
- V_INITは実行設定の`conditions.v_init`から出力する。`build.py`は元モデルの初期電位を明示する。
- 非数値・非有限値・負の密度、重複、未対応の機構・配置・パラメータを拒否する。温度34℃、体細胞ek=−107 mV・ena=53 mVを確認する。
- vanillaへのKv1_1指定はエラー。CSVは対応するbionetliteで再生成する。

## 検証基準

| 検証 | 条件・基準 |
| --- | --- |
| 定常値・時定数 | −120～60 mV、1 mV刻みと−45 mV。独立式・元MODと比較、相対・絶対許容差1e−12 |
| 初期化・電圧ステップ | −90→−40、−40→−100、−107→−107 mV。dt=0.1/0.05/0.025 ms、20 ms。解析解・元MODと比較、相対・絶対許容差1e−10。反転電位で電流0 |
| 電流・面積換算 | 2面積で実際の`calc_lhs_and_rhs`と独立式を比較 |
| 入力生成 | BMTK→bionetlite→CSV→Cで密度と総コンダクタンスを照合 |
| 無効時回帰 | 同じJSONから生成したvanillaとgbar=0でv.dat/s.datが一致 |
| 有効時 | gbar=0.004で有限値の出力を確認 |
| 故障注入 | 4乗→3乗、温度補正なし、換算係数の誤りを検出 |

元MODの電圧固定検証は、状態更新中のgbarを0にし、各評価点で戻して`fcurrent`を計算する。ゲートがgbarに依存しないことを利用する。

[電流記録](kv1_1-recording.md)で追加前後の膜電位・各チャネル電流を可視化し、観測の有無で波形・発火が一致することを確認する。
全細胞のBioNet一致、全区画配置、MPI、別温度、ゲート電流は検証対象外。
