# 配布するソースと検証用コピー

リポジトリにはカーネルとflavor、入力生成、共通のエージェント設定、利用者向け文書、同梱例、テスト、参照データとライセンスを置く。

個人の`LOCAL_ENV.md`、仮想環境、外部参照のcheckout、計算結果はGit管理対象外とする。開発過程の計画・会話・評価用の依頼・過去の実験結果は、公開するソースツリーの外で保管する。

## ソースを書き出す

```sh
python tools/export_repository.py --output ../agentic_neulite-release
```

現在の作業ツリーから公開用のファイルとディレクトリをコピーする。古い開始スナップショットやGit履歴は使わない。出力先が存在する場合は停止するため、既存コピーへ混ぜず、新しいディレクトリを指定する。

`LOCAL_ENV.md`、`.git/`、`_runs/`、仮想環境、外部参照、ビルド生成物は含めない。Claudeのスキルリンクはリンク先とともに保持する。配布対象を追加した場合は`tools/export_repository.py`の一覧も更新する。

## 検証用コピーを使う

書き出したフォルダで[環境準備](agent_usage.md#環境準備)と[テスト](testing.md)を行う。既存環境を利用する場合も、公開ソースへ個人のパスを埋め込まず、コピー後に`LOCAL_ENV.md.example`から設定する。

このソースを`codex`または`claude`で開き、通常の依頼で使う。撮影する場合も同じ手順で実行する。
